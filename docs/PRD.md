# PRD — 팀 편성 웹 앱

## 배경

데이터과학 미니프로젝트(AI-X) 중간과제. 요구사항의 원천은 항상 `중간과제 공고.pdf`이며, 이 문서는 그 요구사항을 제품 관점에서 요약한다.

## 목적

학생들이 팀 프로젝트를 위한 팀을 스스로 편성하는 웹 앱을 만든다. 모집이 끝난 뒤 팀이 없는 학생은 AI가 규칙에 맞게 배정하고, 앱은 AI의 답을 규칙으로 검사해 규칙을 지키는 배정만 확정한다.

## 사용자

| 사용자 | 하는 일 |
|---|---|
| 학생(가상) | 학번/비밀번호로 로그인, 팀 목록 확인, 팀에 지원, 내 팀에 들어온 지원에 투표 |
| 관리자(교수) | `admin`으로 로그인, 명단 CSV로 초기화, 모집 마감, AI 배정 실행, 배정안 확정 |

## 핵심 기능

1. **로그인**: 학번+비밀번호(bcrypt 해시 비교). 관리자는 `admin` + `ADMIN_PASSWORD`.
2. **명단 올리기**: CSV(UTF-8 BOM) 업로드 + 팀 수 입력 → 학생/빈 팀으로 초기화(기존 지원·투표·팀원·마감 표시 전부 초기화).
3. **지원과 투표**: 빈 팀은 즉시 승인. 팀원 있는 팀은 팀원 전원 찬성 시 승인, 한 명이라도 거부하면 즉시 거절. 필수 포함 역할(기획자, 웹 프로그래머) 자리가 부족해지는 지원은 애초에 막음. 승인 직전에 규칙을 한 번 더 검사함.
4. **모집 마감**: 대기 중인 지원은 전부 거절. 1명뿐인 팀의 학생은 팀에서 빠져 "팀이 없는 학생"이 됨.
5. **AI 배정**: 팀이 없는 학생을 OpenRouter 모델 1차→2차→3차 순으로 호출해 배정받음. 모델마다 전체 120초 제한. 검사(배정 누락 없음·중복 없음·2~4명·주 역할 중복 없음·필수 포함 역할 충족)를 통과한 안만 보여줌. 3차까지 실패하면 앱이 직접 전수 탐색으로 배정함.
6. **배정 확정**: 관리자가 확인 후 확정하면 DB에 저장.
7. **다른 사람의 변경 보기**: 팀 목록이 5초마다 자동으로 갱신됨.
8. **DB 일시정지 방지**: 매일 1회 배포 주소를 호출하는 GitHub Actions 워크플로.

## 성공 기준

- 부록 1~3(쉬움/중간/어려움) 연습 시나리오를 처음부터 끝까지 수동으로 실행했을 때, 각 단계의 결과 안내 첫 단어가 공고의 기대 결과와 일치한다.
- `rules.py`/`ai_assign.py`의 pytest 단위 테스트가 전부 통과한다.
- 배포된 Streamlit 주소에서도 위 시나리오가 동일하게 동작한다(배포 후 스모크 테스트).

## 범위 밖

- 실제 학생 개인정보(가상 명단만 사용).
- 구글 로그인(`st.login`) — 채점자가 여러 학생으로 동시에 로그인할 수 없어 이 과제에서는 쓰지 않음.
